# JavaScript JSON Formatter

This project reads a JSON dataset and formats each entry into a human-readable sentence.

## Output format

Article "TITLE" (Page ID PAGEID) was created at MONTH, DAY, YEAR.

## How it works

- Iterates through a list of article objects
- Formats the creation date into a readable form
- Renders results into the HTML page

## How to run

Open `index.html` in a browser.
